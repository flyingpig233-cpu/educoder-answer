# Educoder 实训答案归档

通过 Educoder++ 的 `educoder-core` 获取授权课程的实训作业。归档日期：2026-10-15（Asia/Shanghai）。未向头歌保存答案、提交评测或运行线上测试。

当前归档 **1 门课程、18 个作业、121 道题**。116 道题通过全部 **207 个平台公开样例**；1 道题没有公开样例，使用题面数学定义构造的本地测试通过；4 道题缺少完整规则，按用户要求留空。隐藏测试未获取，不对隐藏测试或线上通关作出保证。

## 检索

查看 [题目索引](INDEX.md)，或在 [index.json](index.json) 中按题目原名、作业 ID、关卡序号检索。原始标题保存在 `title` 和 `listed_title`，以 `(course_id, homework_id, position)` 唯一定位题目。

```text
课程原名 [课程ID]/
  作业原名 [作业ID]/
    关卡序号 关卡原名/
      题目.md               原始 Markdown 题面
      task.json             原始标题、平台可编辑路径、样例数量及验证状态
      samples.json          平台公开样例，仅保存输入与预期输出
      starter/              读取时的代码，保留平台原始路径
      answer/题目原名.c      独立可编译的本地答案
      resources/            文件操作题必需的真实辅助文件（如有）
      run.json              命令行参数、输出文件等本地测试约定（如有）
      local-tests.json      题面推导的测试，明确区别于平台样例（如有）
      skip.json             留空原因（仅规则不完整的题目）
```

Windows 不允许文件名含 `/` 等字符，故使用可逆的 `%` 加四位十六进制 Unicode 编码。例如题名中的 `/` 编码为 `%002F`。原名可从元数据精确恢复；作业 ID 和关卡序号避免重名冲突。

答案当前用于本地验证。平台要求填写头文件表达式或函数时，需按照 `editable_paths` 迁移相应表达式或函数，不应把含 `main` 的完整程序直接粘贴进头文件。多文件题保留 `file.h`、`file2.c` 并一起编译。

## 本地复验

需要 Python 3 和 PATH 中的 GCC（C11，支持 UTF-8）。在仓库目录执行：

```powershell
python verify.py --update-index
```

[verification.json](verification.json) 记录逐题、逐样例结果和测试来源。编译限时 30 秒，样例执行限时 5 秒。每个样例使用 `.build/` 下的独立临时目录；文本、矩阵、二进制输出不污染答案目录。构建产物不进入 Git。

普通输出比较统一 CRLF/LF，并忽略末尾换行，保留其他空格与字符。文件题比较真实生成的输出文件。命令行题将样例首行解析为参数，其余内容用作标准输入。

迷宫题的三个公开样例具有相同输入、分别列出三条路径。程序按题意输出所有路径及编号；验证器独立枚举所有简单路径，要求程序输出集合完全一致且包含全部公开路径，不把三个互相冲突的单路径输出视为三次精确 stdout 比较。

“程序修改替换(1)”（作业 4139769，第 4 关）没有公开样例。`local-tests.json` 根据题面 `1! + … + n!` 的定义使用 Python `math.factorial` 计算 1 至 20 的部分和，状态为 `statement_examples_passed`，不计入公开样例通过数。

掷骰子题的随机序列依赖平台 libc。本地程序采用独立编写的兼容实现，使 Windows 上的序列与题目的公开样例一致；算法参考 [glibc random_r.c](https://sourceware.org/git/?p=glibc.git;a=blob;f=stdlib/random_r.c)。

题面中个别说明与公开样例的输出格式不同，已实现答案按公开样例保留标点、缩写、空格及行数；例如月份使用 Jan 等缩写，杨辉三角样例实际包含第 0 至第 n 行。图示保留原题 Markdown 的附件引用，离线阅读时附件图片可能不可用。

## 数据边界

凭据从仓库外的用户文件读取，未复制进归档。归档不包含 Cookie、Token、真实登录账号、个人实训实例标识、用户 ID 或提交上下文。初始代码是读取时已有的内容，可能已经包含答案，仍与本次验证过的 `answer/` 分开保存。

数据读取、签名和解码复用 [Educoder++](https://github.com/flyingpig233-cpu/educoder-plus-plus) 的 core；导出工具的源码及运行方式见 [tools](tools/README.md)。
